SIP & SLICE — LOGIN / SIGN UP PAGE

File: auth.html

Preview locally: open auth.html in a browser. It is a standalone responsive page with login/signup tabs, form validation, password visibility toggle, and demo status messages.

Add to your GitHub Pages site:
1. Open the Princerabbani/sip-and-slice repository.
2. Upload auth.html to the same root folder as index.html.
3. Commit the file. It will be available at https://princerabbani.github.io/sip-and-slice/auth.html after GitHub Pages deploys.
4. To link it from the home page, add <a href="auth.html">Log in / Sign up</a> inside the homepage navigation.

IMPORTANT SECURITY NOTE:
This is a front-end UI only. It deliberately does not store passwords or create accounts. For real login/signup, connect Firebase Authentication, Supabase Auth, or a secure server-side authentication provider. Google sign-in and password reset are visual placeholders until configured.
